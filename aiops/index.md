# FortiAIOps

## Hands-on Lab Guide v1.1

!!! info "Lab Overview"
    This hands-on lab provides comprehensive experience with FortiAIOps v3.0.0, covering initial setup, device integration, monitoring capabilities, and AI-powered insights across the Fortinet Security Fabric.

---

## Lab Objectives

The FortiAIOps vision is to provide real-time insights and visibility across the entire Fortinet Fabric, rather than just the edge or wireless network, with the ultimate goal of improving the user experience.

This lab aims to:

- **Familiarize** you with FortiAIOps provisioning processes
- **Demonstrate** key features and functions through hands-on experience
- **Provide** knowledge needed for proof of concepts and demonstrations
- **Ensure** proper configuration for comprehensive data collection
